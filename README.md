# BooksMap

> 부산 공공도서관의 도서 소장·대출 상태와 방문 정보를 한 곳에서 확인하는 통합 검색 서비스

BooksMap은 부산 지역 공공도서관을 대상으로 원하는 도서를 검색하고, 해당 도서를 보유한 도서관의 대출 가능 여부와 위치를 비교할 수 있도록 돕는 반응형 웹 서비스입니다.

도서관별 홈페이지를 각각 방문하지 않아도 검색 결과를 한 번에 확인하고, 현재 위치 또는 직접 입력한 출발지를 기준으로 도서관까지의 거리와 예상 이동시간을 비교하는 것을 목표로 합니다.

> 현재 프로젝트는 MVP 기획 및 데이터/API 검토 단계입니다. 상세 요구사항은 [PRD.md](./PRD.md)를 참고해 주세요.

## 주요 기능

- 부산 공공도서관 통합 도서명 검색
- 도서관별 소장 여부 및 대출 상태 확인
- 도서관명과 주소를 포함한 검색 결과 제공
- 검색 결과 도서관을 지도에서 비교
- 현재 위치 또는 주소 직접 입력을 통한 출발지 설정
- 도보·대중교통 기준 거리 및 예상 이동시간 확인
- 검색 결과 없음, API 오류, 위치 권한 거부 등 예외 상황 안내
- 모바일과 데스크톱을 지원하는 반응형 화면

## 사용자 흐름

```text
도서명 입력
    ↓
부산 공공도서관 통합 검색
    ↓
도서관별 소장·대출 상태 확인
    ↓
지도에서 위치 비교
    ↓
출발지 설정
    ↓
도보·대중교통 거리와 예상시간 비교
```

## MVP 범위

### 포함

- 반응형 웹앱 기본 화면
- 도서명 기반 통합 검색
- 도서관별 검색 결과 목록
- 도서관명·주소·보유 여부·대출 가능 여부 표시
- 지도 마커와 검색 결과 목록 연동
- 현재 위치 또는 출발지 주소 기반 이동 정보
- 도보·대중교통 이동수단 선택
- 검색·데이터·위치·지도 관련 오류 상태 처리
- 도서관별 데이터의 내부 표준 형식 정규화

### 제외

- 회원가입 및 로그인
- 찜·즐겨찾기와 검색 기록
- 도서 예약·대출 신청
- 저자·ISBN·출판사·주제 검색
- 도서관 좌석 정보 및 운영 기능
- 알림·푸시 메시지
- 네이티브 iOS/Android 앱

## 데이터 및 외부 서비스

실제 구현에 앞서 다음 항목을 검토하고 확정할 예정입니다.

- 부산 공공도서관 목록 및 도서 검색을 제공하는 공식 데이터 출처
- 도서관별 API 또는 공공데이터의 검색·대출 상태 필드
- 데이터 갱신 주기와 대출 상태의 의미
- API 인증 방식, 호출량 제한, 캐시 및 CORS 정책
- 카카오맵 지도·주소 검색·지오코딩·길찾기 API의 사용 범위와 비용
- 공공데이터 및 외부 서비스의 이용 조건과 출처 표기 방법

대출 상태가 없거나 불명확한 경우 임의로 `대출 가능` 또는 `대출 불가`로 표시하지 않고 `상태 확인 필요`로 안내하는 것을 원칙으로 합니다.

## 완료 기준

MVP는 다음 핵심 흐름이 모바일과 데스크톱에서 모두 동작하면 1차 완료로 봅니다.

- 사용자가 도서명을 입력해 검색할 수 있습니다.
- 부산 공공도서관 검색 결과를 한 화면에서 확인할 수 있습니다.
- 결과별 소장 여부와 대출 상태를 확인할 수 있습니다.
- 결과 도서관을 지도에서 확인할 수 있습니다.
- 현재 위치 또는 주소 입력으로 출발지를 설정할 수 있습니다.
- 도보·대중교통 기준 거리와 예상시간을 비교할 수 있습니다.
- 위치 권한 거부 및 외부 API 오류가 사용자에게 명확히 안내됩니다.
- 실제 데이터와 외부 API의 이용 조건을 준수합니다.

## 개인정보 및 보안 원칙

- 현재 위치와 직접 입력한 출발지는 서비스 목적에 필요한 범위에서만 사용합니다.
- MVP에서는 출발지 위치를 서버나 사용자 계정에 저장하지 않습니다.
- API 키와 서버 인증정보를 저장소에 커밋하지 않습니다.
- 외부 API 키는 사용 가능한 경우 도메인 제한 등 제공자의 보호 기능을 적용합니다.

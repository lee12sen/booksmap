# Deployment Frequency

## 목적

프로덕션 환경에 애플리케이션을 얼마나 자주 배포하는지 측정한다.

## 초기 측정 기준

초기에는 Vercel Production 배포 횟수를 기준으로 배포 빈도를 측정한다.

## 측정 방법

- 대상: Vercel Production 배포
- 기간: 주간 또는 월간
- 계산: 해당 기간의 Production 배포 횟수

## 예시

측정 기간: 2026-10-01 ~ 2026-10-07

Production 배포 횟수: 5회

배포 빈도: 주 5회

## 확인할 항목

- Production 배포인지 확인한다.
- Preview 배포는 제외한다.
- 실패한 배포를 포함할지 기준을 정한다.
- 같은 배포를 중복해서 세지 않는다.
- 측정 기간을 함께 기록한다.
